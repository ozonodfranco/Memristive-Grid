# Memristive Grid Video Processing 🧠⚡

This repository contains the source code, simulation models, and experimental testbenches accompanying the chapter **"A Graph Theoretical Approach for In-Pixel Video Processing using Flux-Controlled Memristive Grids"** published in IntechOpen. 

The project demonstrates the use of an in-pixel neuromorphic architecture based on flux-controlled memristors for visual processing. It includes circuit-level simulations, edge detection evaluation, and continuous video processing that emulates biological retinal persistence.

---

## 📂 Repository Structure

The repository is divided into three main modules to ensure the reproducibility of all the tests presented in the chapter:

### 1. `electrical simulation/` (Circuit-Level Simulation)
Validates the transient dynamics of the resistive grid using both standard nodal simulators and optimized symbolic cores.
* **`simulation python/`**: Contains `Red.py`, a Numba-accelerated (JIT) simulator that processes an input image, generates the flux state (edges), and exports the data in `.dat.ngspice` format.
* **`simulation qucs/`**: Includes schematics (`.sch`), Spice models for the memristors, and netlists to reproduce the behavior in Qucs-S / Ngspice.
* **Response scripts (`plot2XM.py`)**: Extract, scale (using SI prefixes), and plot the time evolution of the variables of interest (Voltage and Memristance) using Polars and Matplotlib.

### 2. `image/` (Computer Vision Evaluation - BSDS500 Benchmark)
Quantifies the memristive grid's performance in edge detection against the popular Canny algorithm and human ground truths.
* Uses images from the Berkeley Segmentation Dataset (BSDS500).
* **`benchmark.py`**: Evaluates spatial tolerance and calculates Precision-Recall metrics (F1-Score ODS/OIS and Average Precision).
* Contains folders for inputs, human annotations (`ground_truth_img`, `ground_truth_mat`), and outputs generated by Canny and the Memristive Grid.

### 3. `video/` (Video Processing and Retinal Persistence)
Demonstrates the grid's intrinsic neuromorphic response when processing continuous video sequences, successfully emulating human visual memory.
* **`without persistance/`**: Uses `Grid.py` to process video frame-by-frame without maintaining memory of previous states.
* **`with persistance/`**: Uses `Grid-M.py` to dynamically process the video by sharing the grid's state between frames, creating a "trail" or short-term memory effect.
* **`quantitative persistance response/`**: Contains `persis.py`, which extracts metrics, quantifies the energy of movement versus the pixel of the trail, and plots the instantaneous vs. accumulated response.

## 🛠️ Requirements and Installation

To run the scripts in this repository, you will need **Python 3.8+** and the following libraries[cite: 2, 3, 4]:

```bash
pip install numpy opencv-python matplotlib numba scipy polars

Additionally, to replicate the experiments in the simulation qucs/ folder, you will require:

Qucs-S (Quite Universal Circuit Simulator with SPICE).

Ngspice configured as the simulation engine in Qucs-S.

🚀 How to Reproduce the Experiments
A. Electrical Simulation
Navigate to electrical simulation/simulation python/.

Place your test image in the input/ folder.

Run python Red.py. The edge maps and .dat.ngspice data will be saved in the output/ folder.

Run python plot2XM.py in the response folder to generate the transient response plots.

B. BSDS500 Benchmark
Navigate to the image/ folder.

Ensure that the output, output_canny, and ground_truth_img folders contain the required data.

Run python benchmark.py.

The script will generate a Precision-Recall scatter plot comparing the ODS, OIS, and AP of our memristive network against Canny and human annotations.

C. Video Persistence
To test the persistence effect, navigate to video/with persistance/.

Run python Grid-M.py. The script will decompose the input video into temporal frames, mathematically process the matrix, and reconstruct the video with the retinal effect.

For the comparative analysis, run python persis.py inside quantitative persistance response/ to visualize the difference in activity and memory in a plot.
